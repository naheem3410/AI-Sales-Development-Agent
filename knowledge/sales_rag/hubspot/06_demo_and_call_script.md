# HubSpot — Demo & discovery call script (outline)

## Opening (30 seconds)
- Confirm role, stack (HubSpot tier if known), primary motion (inbound vs outbound vs ABM).
- Set agenda: discovery → tailored story → demo → next step.

## Discovery questions
1. How do leads enter HubSpot today (forms, imports, ads, outbound)?
2. Who owns **sequence** design — marketing, SDR leadership, RevOps?
3. What metric is failing (reply rate, SQL rate, speed-to-lead, meeting creation)?
4. What content sources are **approved** for reps (brand guidelines, battlecards)?

## Demo flow (adapt to your product)
1. Show **before**: generic or manual prep.
2. Show **after**: grounded personalization using **your** knowledge base + HubSpot context.
3. Show **guardrails**: what the model can/cannot say.

## Close
- Propose **pilot cohort** (one segment, one region, one team).
- Book technical scoping if needed for integrations.

## Follow-up email bullets
- Recap pains, agreed success metric, timeline, stakeholders.
